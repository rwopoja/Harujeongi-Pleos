# 하루전기 · 이동과 충전 계획 도우미

여러 경유지를 말하거나 입력하고, 예상 이동거리와 사용자가 정한 차량 정보로 하루 일정의 전력 소비와 최종 잔량을 계산하는 공모전용 Android 프로토타입입니다. 현재 구현·검증 범위는 아래와 같습니다. 실제 차량용으로 배포하거나 주행 가능 여부를 보장하는 제품은 아닙니다.

## 실행 및 확인

- APK와 Android 실행 검증 결과: [Actions 빌드 목록](https://github.com/rwopoja/MyCabin-Pleos/actions/workflows/submission-demo.yml). 대상 커밋의 성공한 실행에서 `MyCabin-signed-APK-and-Android-demo` 산출물을 내려받습니다. 저장소의 예전 MyCabin APK는 이번 하루전기 앱이 아닙니다.
- Android 9(API 28) 이상 기기 또는 에뮬레이터에 설치합니다. Pleos 전용 SDK 기능은 Pleos Connect 환경 및 해당 서비스·권한이 필요합니다. 서명이 다른 이전 설치본은 제거해야 할 수 있으며 이때 앱 내부 기록이 삭제됩니다.
- 일반 PC에서 화면 확인: `python -m http.server 8080 --directory web` 실행 후 `http://localhost:8080/ev-day.html`을 엽니다. 브라우저에서는 Android 음성·알림·지도 연결을 사용할 수 없습니다.
- 소스 빌드: JDK 17, Android SDK Platform 35 및 Build Tools 35.0.0을 설치하고 `ANDROID_HOME`, `JAVA_HOME`을 지정한 뒤 `python scripts/build_local.py`를 실행합니다. Pleos Nexus와 Maven 저장소 접근이 필요합니다. 결과는 `apk/김재윤_마이캐빈_release.apk`입니다. 개발용 키는 로컬에서 생성하므로 안정적으로 업데이트·배포하려면 본인이 보관하는 키를 사용해야 합니다.

## 사용 순서

1. 배터리 잔량, 사용 가능 용량, 예상 전비, 목표 여유, 정차 시간과 소비전력을 입력합니다. Pleos 배터리 조회 버튼은 실제 지원 환경에서만 응답할 수 있으며, 연결 실패 시 수동 입력합니다.
2. `오늘 일정 말하기`를 누르거나 장소를 직접 입력합니다. 간단한 한국어 연결 표현을 분리한 결과는 **반드시 사용자가 확인하고 적용**합니다. 음성 인식·안내는 기기의 Android SpeechRecognizer와 한국어 TTS 엔진이 필요합니다. 자유로운 모든 발화의 해석을 보장하지 않습니다.
3. 출발지와 각 목적지를 검색하여 동일한 이름의 여러 결과 중 실제 장소를 선택합니다. 주소와 좌표의 외부 서비스 전송에 명시적으로 동의한 뒤 도로 거리 계산을 요청합니다. 결과는 추정 계산에 반영됩니다. 최신 교통정보나 Pleos 내비게이션 경로를 사용하지 않습니다.
4. 선택한 일정 지점 근처의 공개 지도 충전소 후보를 검색하고 원하는 후보를 누르면 그 충전소를 경유하는 도로 거리를 계산합니다. 후보를 확인한 뒤 적용하고 평균 충전 전력을 입력하면 충전량·시간을 계산합니다. 충전소 영업·고장·이용 가능 여부는 별도로 확인해야 합니다. 충전 전 정차 에너지, 실제 충전 곡선·효율·온도·대기 시간은 반영되지 않습니다.
5. 필요한 경우 같은 Android 기기에 사용자가 직접 시간 알림을 예약합니다. 기기 권한과 절전 설정에 따라 표시되지 않거나 지연될 수 있습니다. 다른 휴대폰으로 전송하거나 시동 여부를 감지하지 않습니다.
6. 일정 종료 후 실제 잔량을 입력해 예측 기록을 저장할 수 있습니다. 충전하지 않았고 실제 거리가 계획과 같다고 확인한 기록이 3개 이상일 때 참고 전비와 과거 평균 절대오차를 표시합니다. 기록은 이 기기에만 저장됩니다.

## 데이터와 한계

- 주소 검색은 Nominatim, 도로 경로는 OSRM 공개 데모 서버, 충전소 후보는 Overpass 공개 서버를 사용하며 입력한 검색어·좌표가 해당 서비스로 전송됩니다. 검색은 이용자가 직접 요청해야 합니다. 공개 서버는 정지·제한되거나 데이터가 누락될 수 있고 상용 서비스 수준의 가용성이 보장되지 않습니다. 지도 데이터 © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright).
- 개인화 전비·정차 소비전력·배터리 사용 가능 용량은 입력과 사용자 확인 기록에 의존합니다. 추위, 고도, 속도, 날씨, 배터리 열화, 주행 중 공조 및 실제 충전량을 충분히 관측하지 못합니다. 예측 정확도·오차 범위는 검증되지 않았습니다.
- Pleos Vehicle SDK 2.3.2를 통한 배터리 잔량 조회 코드는 포함하지만 Pleos 차량 서비스로 정상 값이 돌아오는지 실차·Pleos AVD에서 확인하지 못했습니다. 일반 Android에서 미지원 응답을 확인하는 것은 Pleos 검증이 아닙니다.
- Pleos 내비게이션 목적지 변경 이벤트·자동 재계산, 자동 시동 감지, 다른 기기로의 동기화/푸시, 기상·실시간 교통·충전소 실시간 상태 연동, 실제 주행 데이터 기반 성능 검증은 구현 또는 검증되어 있지 않습니다.
- 추정치는 입력 조건에 따른 참고치입니다. 전력 부족이 예상되거나 불확실한 경우 차량의 공식 안내와 충분한 충전 여유를 우선하세요.

## 시험

```bash
npm ci
node tests/ev-journey-smoke.mjs
node tests/ev-planner.test.mjs
```

두 번째 테스트는 모의 지도 응답으로 음성 일정 확인, 데이터 전송 동의, 오래된 응답 차단, 경로·충전소 우회 적용을 검증합니다. 외부 서비스나 Pleos 실차를 대신하는 시험은 아닙니다. GitHub Actions는 일반 Android 14 AVD(1920×1080, density 160)에서 APK 설치와 기본 계산·Pleos 미지원 처리를 확인합니다. Pleos Connect AVD 버전과 실제 화면 규격은 해당 환경에서 실행해 확인해야 합니다.

Pleos와 현대자동차그룹의 공식 앱이 아닙니다. 제3자 SDK 및 자료 출처는 저장소의 `THIRD_PARTY_NOTICES.md`를 참고하세요.
